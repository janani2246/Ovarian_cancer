# 🧠 Ovarian Cancer Prediction & Care Assistant App

## 📌 Overview
This project is a **Machine Learning-based web application** that helps in:
- Early prediction of ovarian cancer risk
- Providing guidance to patients
- Assisting doctors in managing patient data and follow-up care

The system is designed with **two main users**:
- 👩 Patient
- 👨‍⚕️ Doctor

---

## 🚀 Key Features

### 👩 Patient Module

#### 🔹 Option 1: Risk Prediction
Users can enter:
- Age
- Menopause status (Yes/No)
- Family history (Yes/No)
- Symptoms (12 inputs)

👉 Output:
- Risk Percentage (%)
- Risk Level:
  - 🟢 Low → Healthy
  - 🟡 Medium → Consult doctor
  - 🔴 High → Immediate medical attention

---

#### 🔹 Option 2: Care Plan (Cancer Confirmed)
If cancer is already confirmed, the system provides:

👉 Inputs:
- Patient Name
- Age
- Phone Number
- Risk Level

👉 Outputs:
- 📅 Daily Timetable:
  - 7–8 AM → Exercise
  - 9–10 AM → Breakfast + Medicine
  - 1–2 PM → Lunch + Medicine
  - 7–8 PM → Dinner + Medicine

- 🥗 Diet Plan:
  - Eat fruits & vegetables
  - Avoid junk and oily foods
  - Maintain hydration

- 🔔 Alerts (Basic):
  - Meal reminders
  - Medicine reminders

---

### 👨‍⚕️ Doctor Module

Doctors can:
- Enter patient details
- Add medicines and notes
- View patient information
- Maintain simple consultation records

👉 Benefit:
- Helps doctors track patient history easily
- Supports better decision-making

---

## 🧠 Machine Learning Details

- Models Used:
  - Logistic Regression
  - Random Forest

- Accuracy:
  - Around **92% – 93%**

- Input Features:
  - Age, Menopause, Family history, Symptoms

---

## 🖥️ Technologies Used

- Python
- Flask (Backend Framework)
- Scikit-learn (Machine Learning)
- NumPy, Pandas
- HTML/CSS (Inline UI)
